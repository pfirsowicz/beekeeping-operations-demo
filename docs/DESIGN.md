# Dashboard design

- **Harvest:** Green navigation, light surfaces and honey-coloured accents.
- **Studio:** Neutral/slate alternative, using the same screens and sample data.
- Theme preference is browser-local (`hiveledger-theme-v1`) and does not change colony records.
- UI uses plain HTML/CSS/JavaScript; no frontend build step.

## References and rights

- CRM Starter (9 October 2026) informed general dashboard layout.

## Checks
