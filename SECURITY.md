# Security and privacy scope

HiveLedger is a simplified public demo of an existing beekeeping operations application, using synthetic sample records rather than private operational data. **Do not enter real personal, customer, location or hive records** in the demo, especially when testing on someone else's device.

The GitHub Pages version stores data only in the current browser's localStorage, where it is visible to anyone with access to that browser profile. It has no backend, account system or production credentials.

The optional Node HTTP API is deliberately restricted to the local loopback interface, with no authentication. Do not publish or reverse-proxy this API as-is.

If you find a security issue in this demo, report it privately to the repository owner rather than posting credentials or exploit details in a public GitHub issue. No bounty programme is offered.
