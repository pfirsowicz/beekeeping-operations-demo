# Security and privacy

- The hosted demo uses **synthetic data** in browser `localStorage`; anyone using that browser profile can view it. Do not enter real personal, customer or hive records.
- GitHub Pages has no backend, accounts or production credentials.
- The Node/SQLite API runs **locally on loopback** without authentication. Do not expose it publicly.
- Report security issues privately to the repository owner; do not post secrets or exploit details in public issues.
- No bug bounty programme.
